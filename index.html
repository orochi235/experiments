Experiments

Standalone micro-projects and interactive demos

Tube Lab

Sixteen panels on one WebGL context, each drawing a letter as a swept neon tube — beauty, skeleton and ramp views, with a rail that tunes the tube spec live. Build snapshot from the klieg repo.

Last modified: 2026-08-22

Kaleidoscope Lab

Interactive kaleidoscope & wallpaper-group pattern generator using LEGO part renders from brick-icons; exports PNG/SVG wallpapers.

Last modified: 2026-07-12

Speech Balloon Lab

Descriptor-driven lab for designing speech balloons. Runtime toolbar (stem, font, size) over a SVG preview; side panel for body shape, effect stack (tail / stroke / shadow), and persistence with undo/redo. React + Vite.

Last modified: 2026-05-25

Firehose

Lab for exploring low-effort field review UX patterns. Configurable axes: interaction model, density, default state, error visibility, and control panel layout.

Last modified: 2026-05-07

Perceptual Color System

Interactive tool for building perceptually uniform color palettes using OKLCH, with graded scales, categorical sets, gamut mapping, and export.

Last modified: 2026-05-06

Sky Color Models

Interactive comparison of atmospheric scattering models (Preetham, Nishita, Hosek-Wilkie, CIE) with planetary presets, stellar physics, and style controls.

Last modified: 2026-04-25

Interstellar Horizons

WebGL port of the sky-color models with a planet drum-picker, wall-style preview grid, sci-fi presets, and per-pixel directional ground shading. Vite + WebGL2.

Last modified: 2026-05-11
